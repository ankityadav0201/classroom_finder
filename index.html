ABOUT THIS PROJECT

A practical campus solution

ClassRoom Finder is a student-built prototype intended to make room information easier to find. The institute's published annual report describes academic activity primarily in the New Teaching Block and MPSTEP Building and reports 24 classrooms across its facilities. Individual room allocations, current capacity and live timetables must be confirmed with the institute.

View official IIIT Bhopal annual report ↗
Prototype limitations
  • No automatic occupancy sensors.
  • Room names/locations are transcribed from the uploaded Sep–Dec 2026 timetable; this is not a live timetable feed.
  • Admin changes are stored in this browser only.
  • For shared live data, connect a secure database and server-side authentication.
